# teamProject_10

## 연세대학교 인터넷프로그래밍 수업 팀프로젝트를 위한 레포지토리입니다.

1.	프로젝트 주제 아이디어
앱을 통해 해결하고자 하는 문제는 다음과 같습니다.
서울시 내 휠체어 이용자들이 건물 방문이나 지하철 이용 시 엘리베이터, 경사로 상태 등을 미리 확인하지 못해 겪는 이동 불편을 해소하고자 한다. 이용자 간 실시간 시설 정보를 공유하여 이동의 편의성을 증대하고 사회적 참여를 촉진한다.

2. 앱이름 : 배러어프리(휠체어 이용자를 위한 건물 경사로 및 엘리베이터 정보 공유 모바일 지도)

3. 팀원 : 인터넷프로그래밍 10조(인재익, 박종인, 이성우, 정기준, 허율)
